# Facebook Clone Website

This project is a responsive Facebook Clone website developed as a front-end web development project. The main objective of this project is to recreate the look and feel of the Facebook user interface while improving my HTML, CSS, and JavaScript skills. It was built as a learning project to understand modern web design principles, responsive layouts, and interactive UI components.

## Features

- Responsive homepage that adapts to desktop, tablet, and mobile devices.
- Facebook-inspired navigation bar with logo, search bar, and menu icons.
- Sidebar containing navigation links and shortcuts.
- News Feed section displaying user posts.
- Stories section similar to the original Facebook interface.
- Post creation area where users can write and share posts.
- Like, Comment, and Share buttons for each post.
- Friend suggestions and contacts section.
- Profile page layout with cover photo and profile picture.
- Clean and modern user interface using CSS styling.
- Interactive elements implemented with JavaScript.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Font Awesome Icons
- Google Fonts
